01产品目标

在活动管理后台提供活动发奖记录查询与对账能力，帮助运营和财务按活动、奖品快速核对中奖明细，并将完整结果导出为 XLS 文件留档。

查询与筛选奖品联动明细查看全量导出

02查询与筛选规则

1
活动 ID 精确查询输入活动 ID 后点击“查询记录”，仅允许匹配已存在的活动。活动 ID 为空或不存在时，提示“请输入有效的活动 ID”，不发起查询。
2
奖品名称联动活动 ID 输入有效后，奖品名称下拉框解除禁用，并加载该活动下的全部奖品；活动 ID 发生变化时，奖品选项同步刷新。
3
筛选结果范围只按活动 ID 查询时，展示该活动下全部奖品的发放记录；同时选择奖品名称时，仅展示该活动下该奖品的全部发放记录。

03发奖记录列表

列表默认按照中奖时间倒序展示，最新中奖记录排在最前；默认手机号脱敏。列表表头及字段定义如下：

字段展示规则数据要求
奖品名称展示中奖奖品名称，支持区分 CDK、实物、头框等类型。必填，文本。
中奖时间格式为“年月日 时分”，示例：2025-08-18 21:42。必填，作为首要排序字段。
中奖用户昵称展示用户当前昵称。必填，文本。
中奖用户 NN 号展示用户唯一 NN 号。必填，建议按字符串处理。
中奖用户手机号默认展示前三位 + **** + 后四位；点击“查看”后展示明文。必填；导出时必须为明文。
操作展示“查看详情”按钮，点击后打开详情抽屉。根据奖品类型展示对应详情。
排序规则默认按中奖时间降序（DESC）；当中奖时间相同时，按发奖记录 ID 降序作为兜底排序，保证列表顺序稳定。接口建议支持 sortField、sortOrder 参数。
分页规则默认每页 20 条，初始进入第 1 页；展示总条数、当前页码、上一页/下一页和页码跳转。切换活动、奖品或点击重置后，页码重置为第 1 页。

导出不受分页限制，始终导出当前筛选条件下的全部结果。

04详情抽屉规则

A
CDK 奖品展示 CDK 明文。仅在点击“查看详情”后显示，不在列表中直接暴露。
B
实物奖品展示收货地址。用户未填写地址时显示“地址为空（用户未填写收货地址）”，发放状态标记为“待补充地址”。
C
头框奖品展示头框名称、有效期和发放渠道等头框信息。

05导出规则

用户点击“导出全部结果（XLS）”后，导出当前筛选结果的全部数据，不受分页影响。

项目要求
文件格式Excel 兼容的 .xls 文件。
导出范围当前活动 ID + 奖品筛选条件下的全部结果。
导出表头奖品名称、中奖时间、中奖用户昵称、中奖用户 NN 号、中奖用户手机号。
敏感字段中奖用户手机号导出为明文；页面内仍默认脱敏展示。
空结果无匹配记录时不可导出，并提示“暂无可导出的记录”。

06验收标准

输入有效活动 ID 后，奖品名称下拉框联动刷新。
仅按活动 ID 查询时，结果覆盖该活动全部奖品。
按活动 + 奖品查询时，只返回该奖品全部发放记录。
手机号默认脱敏，点击查看可显示明文并支持收起。
不同奖品类型打开详情后展示对应信息。
导出文件包含全部当前结果，手机号为明文且表头准确。
